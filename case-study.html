Norwich Terrier — Pari

Международный bilingual website, посвящённый Norwich Terrier и Bellami‑Elan Parelyada (Pari).

01 / Context

Проект посвящён Norwich Terrier — Bellami‑Elan Parelyada (Pari). Цель — создать полноценную digital‑платформу: породная информация, выставочная карьера, фотографии, родословная, планы разведения и коммуникация с потенциальными владельцами щенков.

02 / Problem

Информация о собаке, порода, выставки и планы были разрозненны и не имели единого профессионального представления в digital‑формате. Нужен был сайт, который работает для русскоязычной и международной аудитории.

03 / Approach

Определила структуру, user flow и bilingual архитектуру сайта. Спроектировала навигацию, разделы и логику будущего enquiry flow для потенциальных владельцев.

04 / Solution

Bilingual website с полной структурой: информация о породе, профиль собаки, фотографии, родословная и контакт. Сайт развивается — добавляются новые функции и контент.

05 / My Role
  • Product structure
  • UX design
  • Russian / English architecture
  • Content creation
  • Web development
  • AI assistant concept
  • Enquiry flow
  • Admin logic
06 / Tools
Cursor HTML / CSS / JS AI-assisted dev GitHub
07 / Outcome

Работающий bilingual website, опубликованный и доступный для международной аудитории. Проект продолжает развиваться.
